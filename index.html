Professional Self-Assessment

Completing the Computer Science program at Southern New Hampshire University has changed how I approach software development. At first, I focused on making applications work and meeting functional requirements. As I progressed, I paid more attention to application structure, how components work together, and how changes affect them. Developing my ePortfolio gave me an opportunity to revisit an earlier project and apply what I've learned since creating it. It helped me recognize my strengths in problem-solving, software engineering, and database management.

I also developed a better understanding of communication and collaboration in software development. Writing functional code is important, but other developers and stakeholders also need to understand what the application does and why certain decisions were made. In CS 465, I worked on Travlr Getaways, a full-stack application that used MongoDB, Express.js, Angular, and Node.js. The project required balancing customer and administrator needs while keeping the application functional. Creating design documents, diagrams, and API documentation helped me understand how technical information can be communicated to different audiences. Although much of my coursework was independent, clear documentation, consistent code, and understanding requirements prepared me to collaborate and maintain applications.

Other courses introduced less familiar areas. In CS 360, I developed an Android weight-tracking application with user authentication and SMS functionality. This introduced additional considerations involving user information, permissions, and security. In CS 370, I worked with artificial intelligence and reinforcement learning, using algorithms to train an agent and evaluate its performance. These projects helped me understand that different problems require different approaches and that selecting a solution involves considering its functionality, efficiency, and limitations. I've also learned to pay more attention to potential vulnerabilities, input validation, and protecting sensitive information rather than treating security as something to address after development.

My professional goals have also changed throughout the program. I originally planned to pursue a career in cloud software engineering, but starting my own sourdough bakery has made me more interested in using my technical skills to develop something of my own. One of my long-term goals is to create an educational application that helps people better understand sourdough baking. Running a business has given me a different perspective on how technology can solve practical problems, especially when existing resources don't fully meet someone's needs. Whether I pursue traditional software engineering or independent development, I want to create applications that are useful, reliable, and designed with the people using them in mind.

For my capstone, I chose to enhance the Grazioso Salvare Animal Shelter Dashboard that I originally developed in CS 340. The application uses Python, Dash, and MongoDB to help identify animals suitable for rescue assignments. I selected this project because I liked its original purpose and saw opportunities to improve it. For the software design and engineering enhancement, I converted the application from a Jupyter Notebook into a standalone dashboard, reorganized the code into separate modules, and improved the interface and record management functionality. I incorporated staff authentication, input validation, and automated testing. These changes made the application easier to maintain and gave me more experience considering security and application structure during development.

My second enhancement focused on algorithms and data structures. I implemented a weighted scoring system to evaluate rescue candidates based on their suitability for different assignments. Instead of simply filtering animals that met the requirements, the dashboard could rank the ten highest-scoring candidates. I also used a min-heap priority queue to improve efficiency and compared its performance against conventional sorting. For the database enhancement, I focused on improving how the application manages and retrieves information through indexing, query optimization, validation, and performance testing. These enhancements required me to consider computational costs, data integrity, and the trade-offs involved in choosing different solutions.

Together, the three enhancements demonstrate how software engineering, algorithms, and databases contribute to the functionality of a single application. The code review, enhancement narratives, and completed project also show how I identified problems, planned improvements, tested my changes, and documented the results. Working on this portfolio has helped me become more confident in my ability to evaluate existing software and make meaningful improvements rather than starting over whenever something needs to change. More importantly, it demonstrates the skills I've developed throughout the program and how I can apply them to problems beyond the classroom.
