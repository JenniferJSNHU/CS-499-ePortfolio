# Enhancement Two: Algorithms and Data Structures

This enhancement focuses on improving how the Grazioso Salvare Animal Shelter Dashboard evaluates and ranks rescue candidates.

I implemented a weighted scoring system that evaluates animals based on breed and age requirements for different rescue assignments. The dashboard ranks the ten highest-scoring candidates using a min-heap priority queue.

I also compared the efficiency of the min-heap approach against conventional sorting to evaluate computational costs and performance.

This folder contains the enhanced project files and the Milestone Three narrative.
