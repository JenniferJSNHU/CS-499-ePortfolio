# Enhancement One: Software Design and Engineering

This enhancement focuses on improving the structure, functionality, and maintainability of the Grazioso Salvare Animal Shelter Dashboard.

The original application was developed in CS 340 using Python, Dash, and MongoDB. For CS 499, I converted the Jupyter Notebook into a standalone application, reorganized the code into separate modules, and redesigned the dashboard interface.

Additional improvements include staff authentication, input validation, animal record management, and automated testing.

This folder contains the enhanced project files and the Milestone Two narrative.
